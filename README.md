> 💡 **Name suggestion:** Now that the bot serves a broader range of memes and jokes beyond just *boi* memes, a more fitting name would be **MemeVault** — reflecting its growing collection of humor from multiple sources.

**Bot Prefix - `/`**

## Commands

| Command | Description |
|---------|-------------|
| `/boi` | Sends a random *breath in*... BOI meme! |
| `/bois` | Lists all available boi memes (owner can also rename/delete). |
| `/meme` | Fetches a random meme from Reddit. Optionally specify a subreddit. |
| `/dadjoke` | Delivers a groan-worthy random dad joke. |
| `/joke` | Tells a random joke. Optionally choose a category (Programming, Misc, Pun, Spooky, Christmas). |
| `/submit` | Submit a new boi meme image for the owner to review. |
| `/about` | Shows information about the bot. |

All commands are available both as guild installs and as user installs (DMs and cross-server).
